# 计算机组成原理-第三章-系统总线

## 1. 总线的基本概念

&emsp;&emsp;计算机有五大部件，这些部件互连的方式有两种，一种是各个部件之间使用单独的连线，这种是分散连接；还有一种就是将各部件连接到一组公共信息传输线上，称为总线连接；

&emsp;&emsp;对于早期的计算机来说，大部分是分散连接，以运算器为中心结构，内部连线十分复杂；如下图1.7，尤其是当 I/O 与存储器交换信息的时候，还需要经过运算器，导致运算器停止运算，影响了其效率；再后来就是图1.8 的分散连接结构，虽然说 I/O 与主存交换信息可以不经过运算器，也采用了中断、DMA 等技术，CPU 运行效率提高，但是无法解决 I/O 设备与主机之间连接的灵活程度；

![image-20250725084147624](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2025/07/17534041075df373.png)

![image-20250725084155524](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2025/07/175340411517e6fd.png)

&emsp;&emsp;随着发展，人们更希望说可以随时增添或者减撤设备，这个时候就出现了总线连接方式；总线就是连接多个部件的信息传输线，是各个部件共享的传输介质；当多个部件与总线相连时，如果出现了两个及以上的部件同时发送信息，必将造成总线信号冲突，因此，在某一时刻，**只允许一个部件向总线发送信息，而多个部件可以同时从总线上接收相同的信息**；其是许多传输线或通路组成，每条线可一位一位传输二进制代码，一串二进制代码可在一段时间内逐一传输完成；若干传输线则可以同时传输；

![image-20260113081416183](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/1768263256d07c17.png)

&emsp;&emsp;该设备在运行时， I/O 设备与主存交换信息的时候，仍然要经过 CPU ，导致降低效率；因此，又有下面这种单总线的方式，这种在交换信息的时候，原则上不影响 CPU 的工作效率；但因为只有一组总线，某一时刻各部件都要占用总线时，会发生冲突，因此必须要设置总线判优逻辑，让各部件按优先级高低来占用总线；PDP-11 和国产 DJS182 机采用这种结构；

![image-20260113081429306](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/176826326955d3b3.png)

![image-20260113081657436](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/1768263417aea408.png)

&emsp;&emsp;这种就在单总线的基础上开辟一条 CPU 与主存之间的总线，称为存储总线；这组总线速度高，只供 CPU 和主存之间传输信息，既提高传输效率，还减轻了系统总线的负担，保留了 I/O 设备与存储器交换信息时不经过 CPU 的特点；国产 DJS184 采用此类结构

## 2. 总线分类

### 2.1. 片内总线

&emsp;&emsp;片内总线，指代芯片内部的总线，比如说 CPU 芯片内部，寄存器与寄存器之间、寄存器与算逻单元 ALUM 之间的总线；

### 2.2. 系统总线

&emsp;&emsp;系统总线是指 CPU、主存、I/O 设备各大部件之间的信息传输线；因为这些部件通常安在主板或各个插件板上，又称为板级总线或板间总线；按照系统总线传输信息的不同，又可以分为三类：数据总线、地址总线和控制总线；

#### 2.2.1. 数据总线

&emsp;&emsp;用来传输各功能的数据信息，是双向传输总线，其位数与机器字长、存储字长有关，一般为 8,16,32 位；数据总线的位数称为数据总线宽度，衡量系统性能的一个重要参数；如果数据总线宽度为 8 位，指令字长为 16 位，那么  CPU 在取值阶段必须要访问两次主存；

#### 2.2.2. 地址总线

&emsp;&emsp;主要用来指出数据总线上的源数据或目的数据在主存单元的地址或 I/O 设备的地址；地址线的位数与存储单元的个数有关，如地址线为 20 根，则对应的存储单元个数为：2<sup>20</sup>；（从存储器独处一个数据， CPU 要将此数据所在存储单元地址送到地址线上；如果将某数据经过 I/O 输出，那么同样，要将数据送到数据总线外，还需要将输出设备的地址送到地址总线上等；）

#### 2.2.3. 控制总线

&emsp;&emsp;因为数据总线和地址总线都是被挂在总线上所有部件共享的；因此如果保证各部件在不同时刻占用总线使用权，需要依靠控制总线来进行；其是用来发出各种控制信号的传输线，同时起到监视各部件状态的作用；常见的控制信号有如下：

- 时钟：用来同步各种操作；
- 复位：初始化所有部件；
- 总线请求：表示某部件需要获得总线使用权；
- 总线允许：表示需要获得总线使用权的部件已获得控制权；
- 中断请求：表示某部件提出中断请求；
- 中断响应：表示中断请求已被接收；
- 存储器写：将数据总线上的数据写至存储器的指定地址单元内；
- 存储器读：将指定存储单元中的数据读到数据总线上；
- I/O 读：从指定 I/O 端口上将数据读到数据总线上；
- I/O 写：将数据总线上的数据输出到指定的 I/O 端口内；
- 传输响应：表示数据已经被接收，或者已经将数据送至数据总线上；

### 2.3. 通信总线

&emsp;&emsp;这就是计算机之间，或者计算机系统与其他系统间的通信了；可以按照传输方式分为：串行通信和并行通信；

## 3. 总线特性及性能指标

### 3.1. 总线特性

1. 机械特性：在机械连接方式上的一些性能，比如说几何尺寸、形状、引脚的个数和排列的顺序等；
2. 电气特性：总线的每一根传输线信号的传递方向和有效的电平范围；
3. 功能特性：总线中每根传输线的功能；
4. 时间特性：总线中任一根线在什么时间有效；每条总线的各种信号互相存在一种有效时序的关系；

### 3.2 总线性能指标

1. 总线宽度：通常是数据总线的根数；用 bit(位) 表示；
2. 总线带宽：总线的数据传输速率，即单位时间内总线上传输数据的位数；可用：MBps；
3. 时钟同步/异步：总线上数据与时钟同步工作的总线称为同步总线，与时钟不同步工作的总线称为异步总线；
4. 总线复用：一条信号线分时传送两种信号；
5. 信号线数：地址总线、数据总线、控制总线三种总线数总和；
6. 总线控制方式：包括突发工作、自动配置、仲裁方式、逻辑方式、计数方式等；
7. 其他指标：负载能力、电源电压、总线宽度是否可以扩展；

### 3.3. 总线标准

#### 3.3.1. ISA 总线

&emsp;&emsp;ISA 总线为 IBM 为采用全 16 位 CPU 推出；又称 AT 总线；优势：独立于 CPU 的总线时钟，CPU 可以采用比总线频率更高的时钟，有利 CPU 性能提升；缺陷：不支持总线仲裁，不能支持多台主设备系统，且 ISA 上所有数据的传送必须通过 CPU 和 DMA 接口来管理，因此 CPU 花费大量时间控制与外部设备交换数据；ISA 总线时钟频率 8MHz,最大传输率 16Mbps，数据线为 16 位，地址线为 24 位；

#### 3.3.2. EISA 总线

&emsp;&emsp;在 ISA 基础上扩充开放的总线标准，兼容 ISA，从 CPU 分离总线控制权，支持多个总线主控器和突发方式的传输；EISA 总线的时钟频率为 8 MHz，最大传输率可达 33 MBps，数据总线为 32 位，地址中总线为 32 位，扩充 DMA 访问范围为：2<sup>32</sup>；

#### 3.3.3. VESA (VL-BUS) 总线

&emsp;&emsp;局部总线标准，即系统外为两个以上模块提供的高速传输信息通道；VL-BUS 由 CPU 总线演化而来的，采用 CPU 的时钟频率达 33 MHz，数据线为 32 位，可通过扩展槽扩展 64 位，配有局部控制器，最大传输率为：133 MBps；通过局部总线控制器，可以将高速 I/O 设备直接挂在 CPU 上，实现 CPU 与高速 I/O 设备之间的高速数据交换；

#### 3.3.4. PCI 总线

1. 高性能：PCI 总线不依附某个具体处理器的局部总线；为系统提供高速的数据传输通道；与 CPU 时钟频率无关，自身采用 33 MHz 和 66 MHz 的总线时钟，数据线为 32 位，可扩展为 64 位，传输速率 132 MBps 可升级为 528 MBps ；支持突发工作方式（即若被传送数据在主存连续存放，则只需给第一个数据地址，占用一个时钟周期，其后的每个数据传送各占一个周期，不必每次给每个数据地址）；

2. 兼容性：PCI 总线部件和插件接口相对于处理器是独立的；支持所有的目前和将来不同结构的处理器；与 ISA、EISA 总线均可兼容；

3. 支持即插即用；

4. 支持多主设备能力；允许任何主设备和从设备之间实现点对点对等存取；（主设备：对总线有控制权，从设备：没有）

5. 具有处理器和存储器子系统完全并行操作的能力：PCI 总线可以视作是 CPU 与外设之间的一个中间层，通过 PCI 桥路（PCI 控制器）与 CPU 项链；PCI 桥路有多级缓冲，可把一批数据快速写入缓冲器，在这些数据不断写入 PCI 设备过程中，可实现处理器与存储器子系统安全并发工作；

6. 提供数据和地址奇偶校验功能；

7. 支持两种电压标准：5V 和 3.3 V；

8. 可扩充性好；（PCI 总线驱动能力不足，可采用多层结构；）

   ![image-20260116220457816](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/17685723811b1a25.png)

9. 软件兼容性好
10. 多路复用技术，减少总线引脚个数；

#### 3.3.5. AGP 总线

- 显示卡专用的局部总线，基于 PCI 2.1 规范并进行扩充修改而成；

#### 3.3.6. RS-232C 总线

- 穿行二进制交换的数据终端设备和数据通信设备之间的标准接口；

#### 3.3.7. USB 总线

1. 真正即插即用；
2. 很强的链接能力；利用 USB HUB 实现系统扩展；最多可链式链接 127 个外设到同一系统；

![image-20260116221522919](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/17685729236eaa06.png)

3. 标准统一；
4. 连接电缆轻巧，电源体积缩小；
5. 生命力强；一种开放性的不具有专利版权的工业标准；

## 4. 总线结构

### 4.1. 单总线结构

![image-20260113081429306](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/176826326955d3b3.png)

- 上图就是单总线结构示意图，将 CPU、主存、I/O 设备都挂在一组总线上，允许其相互直接交换信息；
- 结构简单，便于扩充；
- 效率低；
- 随着外部设备种类和数量多，如若还是用单总线结构，那么 I/O 设备量很大时，总线发出的控制信号从一端逐个顺序传递到第 n 个设备，其传播的延迟时间就会严重影响系统工作效率；

### 4.2. 多总线结构

#### 4.2.1. 双总线结构

![双总线结构](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/1768741366214212.png)

&emsp;&emsp;将速度较低的 I/O 设备从单总线分离出来，形成主存总线与 I/O 总线分开的结构；其中图中的通道是一个具有特殊功能的处理器；CPU 将一部分功能下放给通道，使其对 I/O 设备具有统一管理的功能，以完成外部设备与主存储器之间的数据传送；其系统吞吐能力可以相当大，适用于大、中型计算机系统；

#### 4.2.2. 三总线结构

![image-20260118210652799](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/176874161386ecdc.png)

&emsp;&emsp;主存总线用来 CPU 与主存之间进行传输；I/O 总线供 CPU 与各类 I/O 设备之间传递信息；DMA 总线用于高速 I/O 设备与主存之间直接交换信息；三总线结构中，任一时刻只可使用一种总线；主存总线与 DMA 总线不可同时对主存进行存取，I/O 总线只有在 CPU 执行 I/O 指令时才可用到；

![image-20260118211122889](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/1768741883326542.png)

&emsp;&emsp;处理器与 Cache 之间有一条有一条局部总线，它将 CPU 与 Cache 或与更多的局部设备连接；Cache 控制机构不仅将 Cache 连到局部总线上，而且还直接链到系统总线上，这样 Cache 就可通过系统总线与主存传输信息，而且 I/O 设备与主存之间传输也不必经过 CPU；还有一条扩展总线，将局域网、SCSI等接口链接起来，支持更多设备；然后扩展总线与系统总线相连，实现总线见传递，提高效率；

#### 4.2.2.3. 四总线结构

![image-20260118211758897](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/1768742279c5de16.png)

&emsp;&emsp;增加了一条高速总线，挂接一些高速设备；通过 Cache 控制机构中高速总线桥或高速缓冲器与系统总线和局部总线相连，使得这些高速设备与 CPU 高密切；低速设备仍然在扩展总线上；

## 5. 总线控制

### 5.1. 总线判优控制

- 主设备与从设备：对总线有控制能力的，成为主设备，否则为从设备；总线上信息传送由主设备启动；

- 多个主设备同时需要使用总线，则需要由总线控制器的判优、仲裁逻辑按一定的有限等级顺序决定哪个主设备可使用总线；
- 总线判优控制可分集中式和分布式；前者将控制逻辑集中一处（如 CPU 处），后者分散在与总线连接的各个部件或设备上；

#### 5.1.1. 链式查询

![image-20260119075916432](https://azwcl-blog.oss-cn-shanghai.aliyuncs.com/picgo/2026/01/1768780779871792.png)

- 三根线用来做总线控制；分别：BS 总线忙，BR 总线请求，BG 总线统一；其中总线统一信号是串行从一个 I/O 接口到下一个；
- 如果 BG 到达的接口有总线请求，则不再下传，意味该接口获得总线使用权，建立总线忙 BS 信号，占用总线；
- 所以，在链式查询中，离总线控制部件最近的设备具有最高的优先级；
- 特点：只需很少几根线则可按一定优先次序实现总线控制，且容易扩充设备，但对电路故障敏感，且优先级低的设备可能很难获得请求；
